Exporting an SVG from Figma with layer names

Paintmap matches each territory to a layer by name. Figma leaves layer names out of SVG exports unless you ask for them.

  1. In Figma, give every territory layer exactly the same name as in your sheet (for example Recife). Case and accents are ignored.
  2. Select the frame that contains the territories.
  3. In the right-hand panel, scroll to Export and set the format to SVG.
  4. Click the ⋯ (three dots) next to the format to open the export settings.
  5. Turn on Include "id" attribute.
  6. Click Export and upload the new file to Paintmap.

Each territory should now carry an id with its layer name, for example <rect id="um" ...>. If Paintmap still finds no names, open the SVG in a text editor and check that the id attributes are there.
